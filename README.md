# Arcane Archives v0.9.42 — Celestial Art Pass

Upload **both** `index.html` and `celestial-skylight.webp` to the **root** of the GitHub Pages repository, replacing the old index. Do not upload the ZIP as a single file.

This build replaces the simplistic procedural skylight artwork with a high-detail original illustrated texture loaded as a real Three.js material. It also adds gilded lattice bosses, architectural cove lighting, dimensional trim, and warmer gallery illumination. The original procedural skylight remains as a fallback if the texture cannot load.

Existing 12,800-book catalog, shelf layout, collision, controls, and localStorage save key are unchanged. The ceiling artwork is a texture asset and needs to be uploaded alongside index.html.

If the ceiling still looks like the old build, verify both files are in the repository root and refresh with `?v=0.9.42`.
